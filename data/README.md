# 🥁 Battery Studio

An interactive drum-learning studio application featuring dynamic overhead spotlight visualizers, Web Audio synth synthesis, and AI-powered rhythm coaching.

## 🌟 Live Demo
[Launch Battery Studio on Streamlit Cloud](https://your-app-name.streamlit.app)

## 🛠️ Features & Tech Stack
- **60 FPS Overhead Spotlight Engine:** Custom HTML5 Canvas rendering localized ceiling beams directly over played drum kit elements.
- **Web Audio API & Tone.js:** Low-latency browser audio synthesis and transport event sequencing.
- **AI Practice Coach:** Integrated Google Gemini API agent analyzing drum event density to output real-time practice drills.
- **Streamlit Cloud Deployment:** Zero-cost hosted infrastructure.
